# Remove.bg

:::info
This page explains the steps you need to follow to set up the remove.bg
connection in Automatisch. If any of the steps are outdated, please let us know!
:::

1. Login to your remove.bg account: [https://www.remove.bg/](https://www.remove.bg/).
2. Create a new api key: [https://www.remove.bg/dashboard#api-key](https://www.remove.bg/dashboard#api-key).
3. Copy the `API Key` from the page to the `API Key` field on Automatisch.
4. Leave the `API base URL` field blank. remove.bg ends its self-serve API on
   1 December 2026; to use another API that accepts the same requests, enter its
   base URL there (for example `https://api.example.com/v1.0`) and use that
   service's API key in step 3.
5. Now, you can start using the remove.bg connection with Automatisch.
